# Tinkhack_landingpage
Creates landing page for TinkHack, the flagship hackathon event of TinkerHub MEC

​A sleek, futuristic, and fully responsive landing page for the Tinkhack 2025 hackathon. This project provides a complete, single-page website to give participants all the necessary information about the event, from the overview and timeline to registration and sponsors.

​Features

​Futuristic UI/UX: Modern design with a "cyberpunk" aesthetic, featuring glowing effects and a clean layout.
​Fully Responsive: Looks great on all devices, from mobile phones to desktops.
​Single-Page Navigation: Smooth scrolling to different sections for a seamless user experience.
​Iconography: Uses Font Awesome for clean and modern icons.
​Custom Fonts: Integrates Google Fonts (Orbitron and Poppins) to enhance the theme.
​Interactive Elements: Includes an interactive FAQ section with expandable answers.

​Sections

​The landing page is organized into the following sections:
​Overview: A brief introduction to the hackathon.
​Timeline: Key dates and milestones for the event.
​Registration: A form for participants to sign up.
​FAQ: An interactive list of frequently asked questions.
​Sponsors: A grid to showcase event sponsors.
​Contact: Information on how to get in touch with the organizers.

​Tech Stack

​HTML5: For the structure and content of the page.
​CSS3: For styling, including layout, fonts, and the futuristic theme.
JavaScript: For interactive elements like the FAQ dropdowns.
